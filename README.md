# 🎨 Portfolio Website

A beautiful and responsive portfolio website showcasing projects, skills, and experience. Built with modern web technologies to create an engaging user experience.

## ✨ Features

- 📱 **Fully Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- 🎯 **Clean and Modern UI** - Professional design with intuitive navigation
- 💼 **Project Showcase** - Display your best work with project details and links
- 🚀 **Fast Performance** - Optimized for quick loading times
- 📧 **Contact Section** - Easy way for visitors to get in touch
- 🎨 **Customizable Styling** - Easy to personalize colors and themes

## 🛠️ Technology Stack

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Text editor (VS Code recommended)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/pushkarsingh-001/Portfolio-website.git
   cd Portfolio-website
   ```

2. **Open the project**
   - Simply open `index.html` in your web browser
   - Or use a local server for development:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. **View in browser**
   - Navigate to `http://localhost:8000` (if using a server)

## 🎨 Customization

### Update Personal Information
- Edit `index.html` to add your name, bio, and contact details
- Update project information in the projects section

### Customize Styling
- Modify `style.css` to change colors, fonts, and layout
- Update CSS variables for easy theme customization

### Add Interactivity
- Enhance `script.js` with additional JavaScript features
- Add smooth scrolling, animations, or form validation

### Add Projects
- Create new project cards in the HTML
- Include project images, descriptions, and links

## 📖 Usage

1. **View your portfolio** - Open `index.html` in a browser
2. **Customize content** - Edit HTML, CSS, and JavaScript files as needed
3. **Test responsiveness** - Use browser dev tools to test on different screen sizes
4. **Deploy** - Upload to GitHub Pages, Vercel, Netlify, or your hosting provider

## 📁 File Descriptions

- **index.html** - Main page structure and content
- **style.css** - All styling and responsive design rules
- **script.js** - Interactive features and animations
- **assets/** - Images, icons, and other media files

## 🌐 Deployment

### GitHub Pages
1. Push your code to GitHub
2. Go to repository Settings → Pages
3. Select main branch as source
4. Your portfolio will be live at `https://username.github.io/Portfolio-website`

### Other Platforms
- **Vercel** - Connect your GitHub repo for automatic deployment
- **Netlify** - Drag and drop or connect to GitHub
- **Traditional Hosting** - Upload files via FTP
